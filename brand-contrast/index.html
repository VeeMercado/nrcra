Using the brand red and yellow

Contrast ratios for the brand red (orange, #F05A28) and yellow (#FFCB2A) against white, navy and black text. Ratios use the WCAG formula, the same one the WebAIM Contrast Checker uses, and each row links to WebAIM with the colours filled in.

Red & yellow elements. To maintain readability, red and yellow shouldn’t be used as background colours for large chunks of text, as standard text colours (white, navy or black) won’t pass contrast requirements. They work well for smaller accents, like title backgrounds or buttons (for example yellow paired with navy).

What this means

  • Yellow: white text fails everywhere (1.52:1). Navy passes comfortably (9.95:1), so yellow is safe for buttons and title backgrounds with navy text.
  • Red: white fails for body text (3.39:1) and only passes as large text. Navy is 4.46:1, just under 4.5:1, so it only passes when the text is large (24px, or bold from about 19px). Black does pass (6.20:1) but is off brand.
  • As text colour: red on white is 3.39:1 and yellow on white is 1.52:1, so neither works for words on a white page.
